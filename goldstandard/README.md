# WSD-Goldstandard

Goldstandard für die Bedeutungsdisambiguierung (WSD) im MHDBDB-Korpus, Teil der Dissertation von
Julia Hintersteiner. Dieses Verzeichnis gehört zum Fork `juliahin/mhdbdb-wsd`, nicht zum
Projektkern.
